## 运行已编译的示例

```bash
cd /home/dell/scale_up_evaluation/ns-3-ub
source .venv/bin/activate
python ./ns3 run --no-build 'scratch/ub-quick-example --case-path=scratch/2nodes_single-tp'
```

这是命令行网络仿真程序。仿真完成后会自动退出，无需常驻后台或访问网页。
重复运行同一个 case 会重新生成该 case 的日志和结果；如需保留旧结果，请先备份其 `runlog/` 和 `output/` 目录。

## 环境与重新编译

使用 Ubuntu 22.04、GCC 12.3、CMake 3.22.1、Python 3.12.9 和 Ninja。
Python 依赖使用项目内 `.venv/`，依赖版本来自工具子模块的 `requirements.txt`。
当前为 Release 构建，启用 Unified Bus 及其必要依赖；MPI、MTP、通用 examples 和单元测试未启用。

如需重建：

```bash
cd /home/dell/scale_up_evaluation/ns-3-ub
source .venv/bin/activate
git submodule update --init --recursive
python -m pip install -r scratch/ns-3-ub-tools/requirements.txt
python ./ns3 configure --enable-modules=unified-bus --disable-examples --disable-tests --disable-mpi --disable-mtp --disable-werror -d release -G Ninja
python ./ns3 build -j 24 ub-quick-example
```

激活虚拟环境后再运行，能保证仿真调用的 Python 后处理脚本使用相同环境。
更多场景见项目 `QUICK_START.md` 和 `scratch/README.md`；本次只验证了上述双节点示例。
